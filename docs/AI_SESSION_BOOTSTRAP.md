## Record statuses precisely

| Label | Required proof |
|---|---|
| `SOURCE` / `REFERENCE` | Official source, repository, commit and license/role known |
| `BUILT` | Code, file or artifact exists; not necessarily running |
| `TESTED_LOCAL` | Test ran and assertions recorded; external integration not presumed |
| `DEPLOYED` | Target host has an observed active release/version |
| `VERIFIED_SCOPE` | The exact named live/synthetic acceptance passed with run ID and timestamp |
| `END_TO_END` | One request/job produced real output and target **acknowledgment**, with one correlation ID |
| `BLOCKED`, `SKIPPED`, `STALE`, `UNKNOWN` | State disclosed with explicit reason and next decisive check |

Never turn a source pin, registered skill, green skipped workflow, demo screen, successful monitor or prepared Chief snapshot into a successful downstream result.

**Minimum evidence tuple:** source link, observed UTC timestamp, workflow ID, run ID and attempt, checked assertion, artifact ID/hash when applicable, result status, cost or `unknown`, side-effect authorization and receiver acknowledgment or `unobserved`. Avoid raw client data, tokens and provider exception strings.

## Existing owners and integration routes

- **GitHub** owns versioned code, CI, deterministic quality checks, bounded scheduled research and reproducible render jobs. Its connected ChatGPT tool does not expose encrypted secret updates or arbitrary workflow dispatch; check tools rather than claiming permissions.
- **Cloudflare** owns the narrow authenticated ARGUS and Switchboard Workers and the distinct ElevenLabs bridge. An available queue/health endpoint is not an active research executor or actual model response.
- **n8n** owns selected reviewed event handoffs, receipt normalization, guarded Data Table storage, deduplication and error classification. Never clone existing live Wix intake, reel review or reel-status triggers. Never turn n8n into a general shell that executes 51 source projects.

- **Muse/Phil/Dot/ARGUS PRIME** are separate roles/services; preserve their distinct permissions and require actual recipient acknowledgment for handoffs.
- **Wix/Stripe/HubSpot/Google Calendar** own storefront/settlement/CRM/scheduling records respectively. **Notion/Drive/Library** own protected knowledge and deliverables; do not place private client or proprietary grant records into this public repository.

## Least-cost, no-duplicate operator policy

1. Check for existing running workflow/task, project issue, source artifact and last execution before creating any new agent/schedule/media render. Reuse a passing artifact where scope and rights allow.
2. Keep `ALLOW_PAID_AI=false`, `ALLOW_APOLLO_CREDIT_SPEND=false`, `ALLOW_OUTBOUND_SEND=false` and any subsystem-specific send/trading kill switches until separately authorized and evidenced. Never bypass provider terms, account permissions or Cloudflare client access restrictions.
3. Prefer source-backed, deterministic read-only QA. Only use optional Replit, GPU media generation, a third-party MCP runtime or additional hosting when it solves a verified gap and cost/ROI justifies it. A user's subscribed plan is not a reason to keep workloads duplicated.
4. Inspect current runtime and connected-app capability **per task**, not once forever. ChatGPT access does not imply GitHub Actions or Muse has equivalent credentials.
5. Keep deployment gates versioned: **code tested → host release confirmed → real output checked → destination received → user/Chief acknowledged**.
6. End with one screen: **Bottom Line · Verified · Blocked · Next one to three actions**, each tied to evidence. Update the existing issue and the owner's private Library snapshot when status actually changes.
