# Nicholas-AI-OS — Hermes Project Context

This repository is the control plane for Nicholas's Mac automation, coding agents, media workers, and verified job state.

## Source of truth
- Treat repository state and returned job/status files as authoritative for remote work.
- A request being queued or a process starting is not completion. Verify terminal state and output.
- For code changes, prefer branch → tests/CI → PR → merge. Do not silently bypass failing checks.
- Preserve existing working integrations; modify incrementally rather than rebuilding from scratch unless required.

## Architecture roles
- Hermes: persistent orchestration, scheduling, memory, skill selection, and task decomposition.
- Codex: coding, debugging, repository inspection, implementation, and verification.
- Agent Skills: specialized procedures loaded only when relevant.
- GitHub: durable remote control plane, version history, job transport, and audit trail.
- Mac worker: executes only repository-controlled, explicitly allowlisted maintenance/media modes.

## Safety boundaries
- Never expose or commit credentials, auth files, tokens, .env contents, keychain data, or private secrets.
- Never add an arbitrary remote-shell job or generic command-execution backdoor.
- Do not publish, send external messages, spend money, modify live payment/pricing, or perform destructive actions without explicit user approval immediately before the action.
- Prefer reversible internal changes and zero-incremental-cost paths.
- Keep unattended model-driven cron disabled unless a model/provider and expected usage cost or quota behavior have been deliberately approved.

## Execution discipline
1. Inspect current state.
2. Choose the smallest tool/skill set that can finish the job.
3. Execute reversible work autonomously.
4. Run relevant tests or direct verification.
5. Read back external mutations.
6. Report actual result, evidence, and any remaining blocker.

## Business optimization
When multiple safe tasks are available, prioritize by expected value: revenue creation/protection, client delivery quality, time saved, recurring automation, reliability, then cosmetic improvements.

## Media rules
For social-video work, finished outputs require real visual footage and an audio stream when narration is requested. Default Reels are vertical 9:16 at 1080x1920 and should use the fast path unless advanced production is explicitly requested.
